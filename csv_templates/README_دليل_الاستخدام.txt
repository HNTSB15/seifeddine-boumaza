دليل استخدام ملفات Excel / CSV للتحكم في موقع سيف الدين بومعزة عبر Supabase
==============================================================================

أهلاً بك يا سيف الدين! تم تبسيط جميع الملفات لتكون عبارة عن "سطر واحد فقط" مخصص للإضافة الجديدة، بحيث تظهر إضافتك الجديدة دائماً كأول عنصر في الموقع تلقائياً.

------------------------------------------------------------------------------
📁 محتويات المجلد (كل ملف يحتوي على سطر واحد فقط للإضافة):
------------------------------------------------------------------------------
1. payouts_template.csv  ->  لإضافة سحب Exness جديد (المبلغ، التاريخ، رقم الفاتورة).
2. reviews_template.csv  ->  لإضافة رأي عميل جديد (الاسم، الدولة، التقييم، الرأي).
3. prices_template.csv   ->  لتحديث سعر أي باقة (NewsX AI، التوصيات...).
4. settings_template.csv ->  لتحديث أي رقم إحصائي (نسبة الفوز، العائد، المحافظ...).

------------------------------------------------------------------------------
🚀 كيف تضيف عنصراً جديداً في 3 خطوات بسيطة؟
------------------------------------------------------------------------------

الخطوة 1:
افتح الملف المطلوب في Excel أو Google Sheets. ستجده سطراً واحداً فقط.

الخطوة 2:
عدل القيم الموجودة في السطر لتطابق السحب الجديد أو العميل الجديد:
- مثال في السحوبات: غير المبلغ والتاريخ ورقم الفاتورة.
- مثال في الآراء: غير اسم العميل ورأيه وتقييمه.
ثم احفظ الملف (Ctrl + S).

الخطوة 3 (الرفع إلى Supabase):
1. افتح حسابك في Supabase (https://supabase.com/dashboard).
2. ادخل على الجدول المطابق (مثلاً payout_records أو client_reviews).
3. اضغط في الأعلى على: [ Insert ] ثم اختر: [ Import data from CSV ].
4. اسحب الملف وأفلته، واضغط [ Import data ].

مبروك! تم الرفع وسيظهر العنصر الجديد كأول عنصر في بداية الموقع مباشرة! 🎉
