==============================================================================
دليل استخدام ملفات Excel / CSV للتحكم في موقع سيف الدين بومعزة عبر Supabase
==============================================================================

أهلاً بك يا سيف الدين! هذه الملفات صُممت لتمنحك تحكماً فائق السهولة في موقعك عبر برنامج Excel أو Google Sheets.

------------------------------------------------------------------------------
📁 محتويات المجلد:
------------------------------------------------------------------------------
1. payouts_template.csv  ->  خاص بسحوبات Exness الموثقة (المبلغ، التاريخ، رقم الفاتورة).
2. reviews_template.csv  ->  خاص بآراء وتقييمات العملاء (اسم العميل، دولته، التقييم، الرأي).
3. prices_template.csv   ->  خاص بأسعار باقات NewsX AI، التوصيات، وإدارة المحافظ.
4. settings_template.csv ->  خاص بنسب الأرباح، الـ Win Rate، روابط التواصل، والمحافظ.

------------------------------------------------------------------------------
🚀 كيف تستخدم هذه الملفات في 3 خطوات بسيطة؟
------------------------------------------------------------------------------

الخطوة 1:
افتح أي ملف تريده بواسطة برنامج Microsoft Excel (أو Google Sheets على هاتفك).

الخطوة 2:
- إذا أردت إضافة سحب أرباح جديد: افتح ملف (payouts_template.csv)، واكتب في سطر جديد:
  المبلغ، التاريخ، رقم الفاتورة... ثم اضغط حفظ (Ctrl + S).
- إذا أردت تعديل الأسعار: افتح (prices_template.csv) وعدل الرقم الذي تريده واضغط حفظ.

الخطوة 3 (الرفع إلى Supabase):
1. افتح حسابك في موقع Supabase (https://supabase.com/dashboard).
2. ادخل على الجدول المطابق للملف (مثلاً جدول payout_records).
3. اضغط على الزر الأخضر في الأعلى: [ Insert ] ثم اختر: [ Import data from CSV ].
4. اسحب الملف وقم بإسقاطه في المربع (أو اضغط Browse واختاره).
5. اضغط [ Import data ].

مبروك! تم تحديث البيانات وسيرى جميع زوار الموقع التحديثات الجديدة فوراً! 🎉

------------------------------------------------------------------------------
💡 نصائح هامة:
- لا تغير أسماء الأعمدة في السطر الأول (Header) حتى يتعرف عليها Supabase تلقائياً.
- إذا أردت تعديل كلمة واحدة أو رقم واحد بسرعة: يمكنك أيضاً النقر مرتين مباشرة على الرقم داخل موقع Supabase بدون الحاجة لفتح الإكسل.
